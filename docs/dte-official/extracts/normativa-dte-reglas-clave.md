# Extracto operativo - Normativa de Cumplimiento DTE

Fuente original esperada: `Normativa de Cumplimiento de los Documentos Tributarios Electrónicos_Versión 1.2 17.11.2025.pdf`.

## Estado de extraccion

El PDF disponible en este entorno no entrego texto util mediante extraccion directa. El archivo parece estar compuesto por paginas sin texto extraible o con contenido no accesible por el extractor usado.

Por seguridad tecnica y legal, este extracto NO inventa reglas de la normativa.

## Regla para Claude Code

Cuando una fase requiera reglas normativas especificas, Claude debe:

1. Revisar si existe una version editable, OCR validado o extracto manual confiable.
2. Si no existe, detenerse y pedir la regla exacta.
3. No implementar validaciones legales basadas en suposiciones.

## Reglas que NO deben implementarse desde este archivo

- Plazos legales de invalidacion.
- Condiciones formales de contingencia.
- Campos obligatorios por tipo DTE no confirmados por schema oficial.
- Reglas fiscales de receptor/emisor no confirmadas.
- Casos de retencion/percepcion no confirmados.
- Tratamiento de notas, exportacion, sujeto excluido o donaciones.

## Uso permitido de este archivo

- Documentar que la normativa oficial existe y debe revisarse antes de fases fiscales avanzadas.
- Bloquear implementaciones especulativas.
- Marcar dependencias pendientes en prompts.

## Recomendacion

Antes de implementar fases de firma/transmision completa, contingencia, invalidacion o validaciones fiscales avanzadas, crear un extracto manual validado de la normativa o usar una version del PDF con texto legible.
